An install of Caliper could not be found. It has no Dock icon, it put up no window, and the one thing it did draw — a strip of four items in the menu bar — is dropped without a word by macOS when the bar is full. Launching it again did nothing at all. This release is about that.

What changed

  • The first launch says where it went. A window, and two screens: what Caliper is and how to get back to it, then which readings are worth the width. It is shown once, to a Mac that has never run Caliper — an update keeps the strip it already has and says nothing.
  • Launching Caliper again brings the window back. From Applications, from Spotlight, from a Dock tile. Previously that gesture had no effect whatsoever, which for an app with nothing on screen meant there was no way back to it.
  • “Show Caliper in the Dock”, in Settings → General. Off by default — a monitor has no business holding a Dock slot with nothing on screen — but on, the tile stays, and the app cannot be lost.
  • A new install starts narrower: CPU, memory and temperature, sharing a single menu bar item. 154 points of menu bar against the 258 the old four-item default took — measured, including the padding macOS puts around each item — and the first-run window prices every module you add. One item rather than three partly for those points and mostly because separate items are dropped from the right one at a time, where one item either fits or does not; a strip macOS has truncated is the failure this release is answering for. Network stays a deliberate choice: at 74 points it is the widest single thing Caliper can put up there.

Nothing about an existing install changes. The strip, the recorded history and every setting are left exactly as they were found.

Requirements

macOS 15 or later, Apple Silicon. Sensors are read on a best-effort basis: what a particular Mac will not report is hidden rather than guessed at.
